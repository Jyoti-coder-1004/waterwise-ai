# 📖 Overview

WaterWise AI is a full-stack MERN application designed to encourage responsible water usage through real-time tracking, AI-driven recommendations, analytics, and community engagement.

The platform enables users to monitor daily water consumption, visualize usage trends, participate in eco challenges, earn eco points, and contribute toward environmental sustainability.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/waterwise-ai.git
```

```
cd waterwise-ai
```

---

## Frontend

```bash
cd frontend
```

```bash
npm install
```

```bash
npm run dev
```

---

## Backend

```bash
cd backend
```

```bash
npm install
```

```bash
npm run dev
```

---

# ⚙ Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection

JWT_SECRET=your_secret_key

GEMINI_API_KEY=your_gemini_api_key

CLIENT_URL=http://localhost:5173
```
